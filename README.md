# ♠ PIXEL HOLD'EM ♥

친구끼리 하는 도트 텍사스 홀덤 — 노리밋, 2~8인.

**하우스 룰:** 플랍이 2장입니다. 바닥 카드가 0 → 2(플랍) → 3(턴) → 4(포스) → 5(리버)장으로 열리고, 베팅 라운드가 5번입니다. 족보는 텍사스 홀덤과 같습니다.

## 실행 방법

### A. Cloudflare에 올리기 (PC 없이, 추천)

`https://pixel-holdem.<내 계정>.workers.dev` 같은 주소가 생기고, 친구들이 폰/아이패드/PC 어디서든 접속합니다.
방은 Cloudflare 저장소(Durable Object)에 저장돼서 서버가 재시작돼도 유지됩니다. 무료 플랜으로 충분합니다.

1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Import a repository** (Git 연결)
2. GitHub 계정을 연결하고 이 저장소를 선택
3. 브랜치를 이 코드가 있는 브랜치로 지정, 빌드 명령은 비워두고 배포 명령은 `npx wrangler deploy` (기본값)
4. **Deploy** → 끝나면 나오는 `*.workers.dev` 주소로 접속

이후 이 브랜치에 푸시할 때마다 자동으로 다시 배포됩니다. 설정은 `wrangler.toml`, 진입점은 `worker/index.js`.

PC에서 직접 배포하려면: `npm install` → `npx wrangler login` → `npm run deploy`

### B. 내 PC에서 돌리기

```bash
node server.js          # Node 18+ 필요, npm install 필요 없음
# → http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 PC IP>:3000`. (`PORT=8080 node server.js` 로 포트 변경)

## 모드

- **연습 모드** — 브라우저 안에서 봇(1~7명)과 플레이. 서버 없이도 동작 (`public/index.html` 을 열어도 됨).
- **온라인 모드** — 방을 만들면 4글자 코드가 생깁니다. 친구는 코드 입력 또는 방 목록에서 참가.
  방장은 게임 시작 / 일시정지 / 봇 추가 / 강퇴 가능. 칩이 다 떨어지면 리바이.

## 3장 포커 (1:1)

연습(봇)과 온라인(친구, 2인 방) 모두 **게임 → 3장 포커**로 선택합니다.

- 각자 3장, 블라인드 후 베팅 한 라운드 → 바로 승부. 공유 카드 없음.
- 족보는 홀덤과 같은 순서: 스트레이트 플러시 > 플러시 > 스트레이트 > 트리플 > 페어 > 하이카드 (A-2-3도 스트레이트).
- 한쪽이 파산하면 처형 후 게임 종료. 리바이 없음. 온라인은 방장이 [새 게임]으로 재시작.

## ☠ 데스매치 모드

연습/온라인 모두 방을 만들 때 모드를 고를 수 있습니다.

- 한 라운드 = 8핸드. 라운드가 끝나면 **칩이 가장 적은 사람이 처형**됩니다 (동점이면 그 판에 가장 적게 건 사람).
- 라운드 도중 **파산하면 그 자리에서 처형**되고 바로 다음 라운드로 넘어갑니다.
- 라운드마다 살아남은 사람 모두 시작 칩으로 리셋. 리바이 없음.
- **최후의 1인**이 남을 때까지. 진행 중에 들어온 사람은 관전만 합니다.
- 봇은 마지막 핸드에 최하위면 필사적으로 올인하고, 여유 있으면 몸을 사립니다.

## 중간에 멈춰도 이어하기

- 연습 모드: 액션마다 브라우저(localStorage)에 자동 저장 → 메뉴의 **이어하기**.
- 온라인 모드: 방 상태를 서버에 저장 (PC는 `data/rooms.json`, Cloudflare는 Durable Object). 탭을 닫거나 서버를 재시작해도
  같은 브라우저로 들어오면 자기 자리로 복귀합니다.
  접속이 끊긴 사람 차례가 오면 30초 후 자동 체크/폴드되어 게임이 멈추지 않습니다.
- 방장이 **일시정지** 하면 현재 핸드까지만 진행하고 대기합니다.

## 봇

봇마다 성격이 있습니다: 바위(타이트·소극), 상어(타이트·공격, 잘 읽음), 미치광이(루즈·공격, 블러핑 많음), 콜중독(뭐든 콜), 여우(균형, 속임수).
자기 스택이 위험할수록 신중해지고, 플레이어별 성향(공격성·폴드 빈도·블러핑 들킨 횟수)을 기억해서 대응합니다.
슬로우플레이, 세미블러핑, 블러핑, 장고(고민), 테이블 토크를 하고, 실력이 낮은 봇은 블러핑할 때 손을 떱니다(가끔은 일부러 떨기도 함).

## 공정성

판정이 최우선입니다. `npm test`로 언제든 검증할 수 있습니다.

- **셔플**: 암호학적 난수(`crypto.getRandomValues`) + 편향 없는 Fisher–Yates. 카드-위치 분포를 카이제곱 검정.
- **족보 판정**: 엔진과 별도로 짠 7장 판정기와 20만 판 + 맞대결 10만 판 대조, 백스트레이트/3페어/트리플 2개/보드 플레이 등 엣지 케이스.
- **팟 분배**: 별도 방식으로 짠 정답 계산기와 2~7인 무작위 올인 2만 판 대조 (사이드 팟, 콜 안 된 금액 반환, 무승부 분배, 홀수 칩은 버튼 왼쪽부터), 칩 총량 보존.
- **베팅 규칙**: 차례 외 액션 거부, 최소 레이즈, 헤즈업 블라인드/순서, BB 옵션, 풀 레이즈가 아닌 올인은 베팅을 다시 열지 않음.
- **정보 차단**: 온라인에선 서버가 각자에게 자기 패만 보냄(덱·남의 패 전송 안 함), 폴드한 패는 끝까지 비공개. 봇도 남의 패를 보지 않고 결정.

## 구조

| 파일 | 내용 |
|---|---|
| `public/poker.js` | 게임 엔진 (족보 판정, 베팅, 사이드팟, 봇 AI) — 브라우저/서버 공용 |

| `server.js` | PC용 서버: 정적 파일 + API + SSE, `data/rooms.json` 저장 |
| `worker/index.js`, `wrangler.toml` | Cloudflare용 서버: Worker + Durable Object |

## 아이패드 / 폰

서버를 켠 PC와 같은 와이파이에서 Safari로 `http://<PC IP>:3000` 접속.
공유 버튼 → **홈 화면에 추가** 하면 앱처럼 전체화면으로 열립니다.
(PC IP 확인: Windows `ipconfig`, Mac `ipconfig getifaddr en0`)
